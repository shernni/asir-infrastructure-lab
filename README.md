# asir-infrastructure-lab
Hands-on IT infrastructure and system administration labs

Date: October 30, 2026
This repository documents my practical learning journey in system administration, virtualization, networking, database management, and cybersecurity.

My goal is to develop real-world technical skills by building, configuring, troubleshooting, and securing IT environments.

Technologies & Tools

Operating Systems: Windows 11, Ubuntu Linux
Virtualization: Oracle VirtualBox
Databases: MySQL, MySQL Workbench


Compatibility note: VirtualBox did not provide an Ubuntu 26.04 guest OS profile. The latest available Ubuntu profile (25.04, 64-bit) was selected while retaining the Ubuntu Server 26.04.1 installation ISO.
